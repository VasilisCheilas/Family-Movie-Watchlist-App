# Family Movie Watchlist API

Ένα RESTful API κατασκευασμένο με Node.js και Express.js για τη δημιουργία και διαχείριση λιστών παρακολούθησης ταινιών (watchlists). Αυτό το έργο ολοκληρώθηκε με επιτυχία στα πλαίσια της πιστοποίησης **Back End Development and APIs** του freeCodeCamp.

## Βασικά Χαρακτηριστικά
* **Ταυτοποίηση Χρηστών (Authentication):** Ασφαλής σύνδεση και εξουσιοδότηση με χρήση JSON Web Tokens (JWT).
* **Λειτουργίες CRUD:** Δυνατότητα δημιουργίας, ανάγνωσης, ενημέρωσης και διαγραφής ταινιών από τις λίστες.
* **File-based Σύστημα Αποθήκευσης:** Διαχείριση και αποθήκευση των δεδομένων τοπικά χωρίς την ανάγκη εξωτερικής βάσης δεδομένων, χρησιμοποιώντας αριθμητικά IDs για την αναζήτηση και επαλήθευση των εγγραφών.

## Τεχνολογίες
* **JavaScript (Node.js)**
* **Express.js** (Web Framework)
* **JWT** (Ασφάλεια / Authentication)

## Δομή του Έργου

Η αρχιτεκτονική του κώδικα ακολουθεί τον παρακάτω διαχωρισμό[cite: 6]:

* `data/`: Περιέχει τα τοπικά αρχεία (JSON) για την αποθήκευση των λιστών και των χρηστών[cite 6].
* `middleware/`: Φιλοξενεί τις λειτουργίες ελέγχου πρόσβασης (π.χ. authenticate, authorize) πριν την εκτέλεση των βασικών αιτημάτων[cite: 6].
* `routes/`: Περιλαμβάνει τη δρομολόγηση του API (auth routes, watchlist routes)[cite: 6].
* `utils/`: Βοηθητικά εργαλεία, όπως η λειτουργία δημιουργίας των JWT[cite: 6].
* `index.js`: Το κεντρικό αρχείο εισόδου και εκκίνησης του διακομιστή[cite: 6].
* `package.json` & `package-lock.json`: Διαχείριση των πακέτων και των εξαρτήσεων του έργου (npm)[cite: 6].
* `.gitignore`: Εξασφαλίζει ότι τα ευαίσθητα αρχεία (όπως το `.env`) δεν ανεβαίνουν στο αποθετήριο[cite: 6].

## Εγκατάσταση και Εκτέλεση Τοπικά

Για να τρέξετε το project στον υπολογιστή σας, ακολουθήστε τα παρακάτω βήματα:

1. **Κλωνοποίηση του αποθετηρίου:**
```bash
   git clone [https://github.com/VasilisCheilas/Family-Movie-Watchlist-App.git](https://github.com/VasilisCheilas/Family-Movie-Watchlist-App.git)
   cd Family-Movie-Watchlist-App/build-a-family-movie-watchlist-api

```

2. **Εγκατάσταση Εξαρτήσεων:**
```bash
npm install

```


3. **Ρύθμιση Μεταβλητών Περιβάλλοντος:**
Δημιουργήστε ένα αρχείο `.env` στον κεντρικό φάκελο και προσθέστε το δικό σας μυστικό κλειδί για το JWT:
```env
JWT_SECRET=το_δικο_σας_μυστικο_κλειδι_εδω

```


4. **Εκκίνηση του Server:**
```bash
node index.js

```


Το API θα ξεκινήσει να λειτουργεί.
